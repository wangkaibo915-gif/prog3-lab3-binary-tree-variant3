# Лабораторная работа 3. Построение бинарного дерева

Вариант 3: `root = 3`, `height = 4`, левый потомок вычисляется как
`value + 2`, правый потомок — как `value * 3`.

Функция `gen_bin_tree` рекурсивно возвращает дерево из словарей с ключами
`value`, `left`, `right`. Корень считается первым уровнем. У листьев поля
`left` и `right` равны `None`. Любой из четырёх параметров можно передать
явно, чтобы заменить значение по умолчанию.

Дополнительно функция `as_namedtuple` показывает хранение того же дерева с
помощью контейнера `namedtuple` из модуля `collections`.

Запуск примера:

```bash
python3 binary_tree.py
```

Запуск тестов:

```bash
python3 -m unittest -v test_binary_tree.py
```

В Google Colab тесты можно запустить командой
`unittest.main(argv=[''], verbosity=2, exit=False)`.
